# Push Stars

Мобильный киберспорт в реальном времени: **PvP-дуэли по калистенике** с локальным компьютерным зрением (**MediaPipe**), синхронизацией матча через **Photon PUN2** и аватарами **Genies SDK**. Backend — **Firebase**.

## Документация

- **[PROJECT_PLAN.md](PROJECT_PLAN.md)** — мастер-план, порядок фаз, стек, правила для агента.
- **[docs/plan/](docs/plan/)** — по одному файлу на фазу реализации (00–17).
- **[docs/architecture/](docs/architecture/)** — Firebase, Ghost Mode, константы.
- **[docs/design/screens-reference.md](docs/design/screens-reference.md)** — описание экранов под UI из макетов.

## Быстрый старт для разработки

1. Прочитать `PROJECT_PLAN.md`.
2. Выполнить фазы по порядку зависимостей (см. граф в мастер-плане).
3. В новом чате с ИИ прикреплять `PROJECT_PLAN.md` + нужный `docs/plan/phase-XX-*.md`.
