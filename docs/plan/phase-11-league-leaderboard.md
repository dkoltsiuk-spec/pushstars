# Фаза 11 — Лига и таблица

## Реализация 2026-09-30

Реализованы Cloud Functions в `functions/src/league.js`, клиент `LeagueClient`, онлайн-часть `LeagueView`, закреплённая строка, страницы по 25 участников и серверные рейтинговые Ghost-сессии. Согласованы месяцы UTC без сброса кубков. Вместо полного пересчёта мест каждые 5 минут сервер считает актуальную позицию при чтении; каждые 5 минут выполняются ротация метаданных сезона и обработка истёкших сессий. Кеш клиента — 60 секунд. Подробности и ограничения: [онлайн-лига](../architecture/online-league.md). Ниже сохранён исходный план; его acceptance criteria требуют отдельного игрового прогона.

## Цель фазы

Вкладка **Лига**: карточка текущего ранга (Bronze/Silver/Gold/Diamond), трофеи, прогресс до следующего порога, список игроков лиги с **закреплённой своей строкой** (всегда видна), таймер до конца сезона (из `seasons/{id}`).

Клиент кеширует список на **`LEADERBOARD_CACHE_SEC`** (60 с). Пересчёт позиций — scheduled CF **`recalculateLeaderboard`** (каждые 5 мин).

## Что НЕ делаем в этой фазе

- Глобальный кросс-лиговый топ.
- Реал-тайм подписки на каждое изменение трофеев.
