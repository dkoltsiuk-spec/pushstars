# Фаза 11 — Лига и таблица

## Цель фазы

Вкладка **Лига**: карточка текущего ранга (Bronze/Silver/Gold/Diamond), трофеи, прогресс до следующего порога, список игроков лиги с **закреплённой своей строкой** (всегда видна), таймер до конца сезона (из `seasons/{id}`).

Клиент кеширует список на **`LEADERBOARD_CACHE_SEC`** (60 с). Пересчёт позиций — scheduled CF **`recalculateLeaderboard`** (каждые 5 мин).

## Что НЕ делаем в этой фазе

- Глобальный кросс-лиговый топ.
- Реал-тайм подписки на каждое изменение трофеев.
