# Фаза 10 — Genies SDK и гардероб

## Цель фазы

Интегрировать **Genies SDK**: отображение аватара на главном экране, в прематче и в результатах; слоты анимаций (idle, victory, defeat, greeting/celebration по продукту). Экран **Гардероб**: список доступной косметики из локального каталога + опционально Firestore `cosmetics/` для unlock-флагов. Сохранение **`avatarState`** в профиле пользователя (клиент только если правила разрешат — иначе через callable `updateAvatarState`).

## Что НЕ делаем в этой фазе

- Battle Pass и IAP (после MVP).
- Полный пайплайн загрузки пользовательских FBX из приложения (документировать отдельно для тебя как 3D-артиста).

## Acceptance criteria

- [ ] Аватар загружается < целевое время на среднем устройстве.
- [ ] Смена предмета одежды отражается после сохранения и перезапуска.
- [ ] Падение SDK не роняет приложение (fallback mesh/sprite).

## Тестирование

Два устройства iOS + Android, проверка памяти при повторном входе на главный экран.
