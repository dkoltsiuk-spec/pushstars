# Фаза 11.5 — Ежедневная цель и недельный async-зачёт

## Цель фазы

Дать игроку повод заходить **каждый день** и соревноваться **без онлайна**, опираясь на CV (фаза 08) и экономику. Два лёгких блока:

1. **Ежедневная цель** — одна понятная задача на день: «сделай N отжиманий» или «побей вчерашний результат». Прогресс виден на главном экране; выполнение кормит стрик (уже в экономике) и даёт XP/бонус. Не требует соперника и сети для подсчёта (синк XP — через `syncOfflineXp`).

2. **Недельный async-зачёт** — соревнование по **сумме** (репы/победы за неделю), а не в реальном времени. Расширяет таблицу лиги (фаза 11): дополнительная вкладка/режим «Неделя» поверх той же инфраструктуры `leaderboard` + `recalculateLeaderboard`, с обнулением по сезонной/недельной границе.

Обе механики дешёвые и убирают зависимость retention-петли от живого PvP.

## Согласованный план ежедневного ритма (владелец, 18.10.2026)

Ревью удержания: Аура — хорошая долгая мета, но причины вернуться завтра нет. Решения владельца:

| Что | Решение |
|-----|---------|
| Огонь (стрик) | День засчитывает **любой** бой или тренировка с повторами. Дни — местные календарные дни, один счёт везде. |
| Цель дня | Сумма отжиманий за день во всех режимах, отдельно от огня. Под игрока: лучший подход до сегодня × 1.5, 20–60, не выше 150. |
| Аура | +1000 за цель раз в сутки; стрик 7 дней +10K, 30 дней +50K — раз за всё время. Ауры за простой вход нет. |
| Заморозка | **Отложена** (владелец, 18.10.2026). Если вернёмся: 1 бесплатная в неделю, запас максимум 2, тратится сама на пропущенный день, не продаётся. |
| Напоминание | Локальное, без сервера: в привычное время игрока, если цель не выполнена; при стрике от 3 — ещё вечернее «огонь гаснет». Не больше 2 в день. Разрешение — после первой выполненной цели. Переключатель в настройках. |
| Аналитика | Отдельный проект PostHog «Pushup Stars» (существующий проект — другого приложения), ~10 событий, возвраты D1/D7 и воронка первого запуска. |
| Экран | Огонь в HUD с тонким кольцом прогресса цели, по нажатию — маленькая карточка; на экране результата одна строка «DAILY GOAL +1000». Нового экрана наград нет. |

Порядок: 1) общий стрик + цель дня + Аура по чекам (`DailyGoal`, `DailyRewards`) — сделано; 2) огонь с кольцом (`DailyGoalRing`) и карточка — сделано, карточка = пузырь подсказки по нажатию на огонь (`HudCurrencyHints`), Аура за цель из тренировки собирается на главной;
3) заморозка — отложена; 4) локальные напоминания — сделано (`com.unity.mobile.notifications` 2.5.0, расписание `ReminderPlanner`, платформа `Scripts/Reminders/LocalReminders`, см. ниже); 5) аналитика (можно параллельно).
XP-бонус за цель (`DAILY_GOAL_XP_BONUS`) пока не подключаем — награда за цель только Аурой.

### Локальные напоминания (как устроено)

- `ReminderPlanner` (Core, чистая функция): привычное время = медиана начала первого подхода за последние 7 активных дней, по умолчанию 19:00, в пределах 9:00–21:00.
  Напоминание о цели — в привычное время сегодня (если цель не выполнена и время не прошло), завтра и послезавтра; «Серия гаснет» — вечером (привычное + 2.5 ч, в пределах 20:00–21:30) при серии от 3 дней: сегодня, если ещё не тренировался, или завтра, если сегодня уже был подход. Не больше двух в день; если вечернее ближе 90 минут к напоминанию о цели, остаётся только вечернее.
- `LocalReminders` (сборка `PushStars.Reminders`, только Android/iOS/Editor) поднимается сам, без сцен: при старте, на главной и при сворачивании приложения снимает все запланированные напоминания и ставит новые. В редакторе только пишет план в консоль.
- Разрешение ОС спрашивается один раз — на главной после первой выполненной цели дня (`reminders.permission_asked` в PlayerPrefs); на iOS запрос при запуске выключен в Project Settings > Mobile Notifications. Переключатель уведомлений в настройках выключает всё.
- Android: канал «Ежедневные напоминания» с обычной важностью (без всплывающих окон), значок — белый силуэт огня `Art/Notifications/notify_icon_small.png` (`icon_small`), напоминания переживают перезагрузку телефона. iOS: баннер + звук, без бейджа.
- Аналитика: `notif_permission` после ответа на запрос, `push_opened` с видом напоминания при открытии из уведомления.
- Тексты — в каталоге локализации (ru/en/pt-BR). Проверено в Editor и компиляцией скриптов игрока под Android и iOS; на телефоне ещё не проверялось.

## Что НЕ делаем в этой фазе

- Сложные цепочки квестов / батлпасс.
- Награды Aura за сырые репы (нарушает дефицитность Aura — см. `economy.md`).
- Отдельный live-лидерборд реального времени (остаётся кеш-модель фазы 11).

## Предусловия

Фаза 08 (CV/счётчик), фаза 11 (таблица и `recalculateLeaderboard` для недельного зачёта), экономика (XP/стрик).

## Поток

1. На старте дня клиент определяет цель: фиксированный таргет по уровню/лиге **или** «вчерашний результат + дельта».
2. Прогресс цели обновляется по ходу любой активности (тренировка/дуэль/ghost), отображается на главном экране.
3. Выполнение → разовый XP-бонус + засчитанный активный день (стрик). Без трофеев (безопасно, как тренировка).
4. Недельный зачёт: суммарные метрики недели пишутся в `leaderboard` (тот же путь, отдельный период), сбрасываются по границе недели.

## Новые константы (добавить в `constants.md`)

| Имя | Значение (предложение) | Назначение |
|-----|------------------------|-----------|
| `DAILY_GOAL_BASE_REPS` | `20` | Базовый дневной таргет (масштабируется уровнем/лигой) |
| `DAILY_GOAL_XP_BONUS` | `75` | Разовый XP за выполнение цели дня |
| `WEEKLY_BOARD_RESET_DOW` | `Mon` | День недели для обнуления недельного зачёта |

Лимит `DAILY_REP_XP_CAP` (150) сохраняется — дневная цель не обходит анти-грайнд.

## Затрагиваемые экраны

Главный экран (1): виджет «Цель дня» с прогресс-баром. Экран Лига (фаза 11): переключатель «Сезон / Неделя».

## Файлы

- `Assets/_Project/Scripts/Economy/DailyGoalController.cs` — расчёт таргета, отслеживание прогресса, выдача бонуса.
- `Assets/_Project/Scripts/UI/Main/DailyGoalWidget.cs`

## Acceptance criteria

- [ ] Цель дня видна на главном экране и обновляется по ходу любой активности.
- [ ] Выполнение цели засчитывает активный день для стрика и выдаёт `DAILY_GOAL_XP_BONUS` один раз в сутки.
- [ ] XP за цель не обходит `DAILY_REP_XP_CAP`.
- [ ] Недельный зачёт корректно обнуляется на границе недели; своя строка подсвечена (как в фазе 11).
- [ ] Оффлайн: прогресс цели копится локально и синкается без дублей через `syncOfflineXp`.

## Тестирование

Перевод даты/часов на устройстве для проверки сброса цели и недели. Airplane-режим: накопление прогресса и синк. Сверка XP-бонуса с constants на staging.

## Связь с дизайном

Виджет цели усиливает «понятность метрик» главного экрана; недельный режим переиспользует макет таблицы лиги без новых экранов.
