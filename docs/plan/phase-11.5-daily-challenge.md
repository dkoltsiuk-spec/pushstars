# Фаза 11.5 — Ежедневная цель и недельный async-зачёт

## Цель фазы

Дать игроку повод заходить **каждый день** и соревноваться **без онлайна**, опираясь на CV (фаза 08) и экономику. Два лёгких блока:

1. **Ежедневная цель** — одна понятная задача на день: «сделай N отжиманий» или «побей вчерашний результат». Прогресс виден на главном экране; выполнение кормит стрик (уже в экономике) и даёт XP/бонус. Не требует соперника и сети для подсчёта (синк XP — через `syncOfflineXp`).

2. **Недельный async-зачёт** — соревнование по **сумме** (репы/победы за неделю), а не в реальном времени. Расширяет таблицу лиги (фаза 11): дополнительная вкладка/режим «Неделя» поверх той же инфраструктуры `leaderboard` + `recalculateLeaderboard`, с обнулением по сезонной/недельной границе.

Обе механики дешёвые и убирают зависимость retention-петли от живого PvP.

## Что НЕ делаем в этой фазе

- Сложные цепочки квестов / батлпасс.
- Награды Aura за сырые репы (нарушает дефицитность Aura — см. `economy.md`).
- Отдельный live-лидерборд реального времени (остаётся кеш-модель фазы 11).

## Предусловия

Фаза 08 (CV/счётчик), фаза 11 (таблица и `recalculateLeaderboard` для недельного зачёта), экономика (XP/стрик).

## Поток

1. На старте дня клиент определяет цель: фиксированный таргет по уровню/лиге **или** «вчерашний результат + дельта».
2. Прогресс цели обновляется по ходу любой активности (тренировка/дуэль/ghost), отображается на главном экране.
3. Выполнение → разовый XP-бонус + засчитанный активный день (стрик). Без трофеев (безопасно, как тренировка).
4. Недельный зачёт: суммарные метрики недели пишутся в `leaderboard` (тот же путь, отдельный период), сбрасываются по границе недели.

## Новые константы (добавить в `constants.md`)

| Имя | Значение (предложение) | Назначение |
|-----|------------------------|-----------|
| `DAILY_GOAL_BASE_REPS` | `20` | Базовый дневной таргет (масштабируется уровнем/лигой) |
| `DAILY_GOAL_XP_BONUS` | `75` | Разовый XP за выполнение цели дня |
| `WEEKLY_BOARD_RESET_DOW` | `Mon` | День недели для обнуления недельного зачёта |

Лимит `DAILY_REP_XP_CAP` (150) сохраняется — дневная цель не обходит анти-грайнд.

## Затрагиваемые экраны

Главный экран (1): виджет «Цель дня» с прогресс-баром. Экран Лига (фаза 11): переключатель «Сезон / Неделя».

## Файлы

- `Assets/_Project/Scripts/Economy/DailyGoalController.cs` — расчёт таргета, отслеживание прогресса, выдача бонуса.
- `Assets/_Project/Scripts/UI/Main/DailyGoalWidget.cs`
- Расширение `Assets/_Project/Scripts/UI/League/LeagueScreen.cs` — режим «Неделя».
- Расширение `functions/src/recalculateLeaderboard.js` — недельный агрегат + сброс по `WEEKLY_BOARD_RESET_DOW`.
- Хранение состояния цели: `users/{uid}/flags` или `PlayerPrefs` + сверка даты (учёт часового пояса проекта — UTC).

## Acceptance criteria

- [ ] Цель дня видна на главном экране и обновляется по ходу любой активности.
- [ ] Выполнение цели засчитывает активный день для стрика и выдаёт `DAILY_GOAL_XP_BONUS` один раз в сутки.
- [ ] XP за цель не обходит `DAILY_REP_XP_CAP`.
- [ ] Недельный зачёт корректно обнуляется на границе недели; своя строка подсвечена (как в фазе 11).
- [ ] Оффлайн: прогресс цели копится локально и синкается без дублей через `syncOfflineXp`.

## Тестирование

Перевод даты/часов на устройстве для проверки сброса цели и недели. Airplane-режим: накопление прогресса и синк. Сверка XP-бонуса с constants на staging.

## Связь с дизайном

Виджет цели усиливает «понятность метрик» главного экрана; недельный режим переиспользует макет таблицы лиги без новых экранов.
