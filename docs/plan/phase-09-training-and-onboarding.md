# Фаза 09 — Тренировка и онбординг

## Цель фазы

Режим **тренировки без ранга**: использует CV из фазы 08. Экран **«Эталонное движение»** с разбивкой фаз вниз / пауза / вверх; во время тренировки — **real-time подсказки** по ошибкам формы. **Гейтинг:** пока не завершена первая обучающая тренировка по упражнению — вкладка дуэли недоступна или показывает только тренировку. При добавлении новых упражнений — тот же паттерн.

Оффлайн: начисление XP локально → очередь на **`syncOfflineXp`** при появлении сети.

## Что НЕ делаем в этой фазе

- Запись Ghost binary и матч против себя (фаза 12).
- PvP по сети (фаза 14).
