# Фаза 16 — Приглашение друга и deep links

## Цель фазы

Прямой вызов на дуэль: пользователь делится ссылкой; получатель открывает приложение с параметрами (**Branch.io** или **AppsFlyer OneLink** — Firebase Dynamic Links не использовать для новых проектов). Создание **приватной Photon-комнаты** по заранее согласованному **invite token** / короткому коду. Fallback: **friend code** из 6 символов без Universal Link.

## Что НЕ делаем в этой фазе

- Соц. лента или чаты.
- Кросс-платформенный spectate.

## Предусловия

Фаза 14.

## Затрагиваемые экраны

Главный экран — входящий челлендж; push тип `friend_challenge` (фаза 15).

## Файлы

- `Assets/_Project/Scripts/Invites/InviteDeepLinkHandler.cs`
- Branch SDK или AppsFlyer SDK в Unity
- `functions/src/invites/createInviteSession.js` (опционально) — серверная валидация токена

## Acceptance criteria

- [ ] Ссылка открывает приложение на iOS и Android с корректной передачей параметров.
- [ ] Истёкший инвайт показывает понятную ошибку.
- [ ] Duplicate join обрабатывается.

## Тестирование

Airplane mode toggle; переход из браузера/Telegram в приложение.

## Связь с дизайном

Виральность — без нового обязательного макета; можно переиспользовать экран поиска с меткой «Вызов от друга».
