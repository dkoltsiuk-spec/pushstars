# Cinema 4D → FBX → Genies (черновик)

Заполняется в фазе 10 под актуальный пайплайн Genies SDK и вашу версию C4D.

1. Моделинг / UV / текстуры одежды в C4D.
2. Экспорт FBX с человекочитаемой иерархией костей, совместимой с требованиями Genies (уточнить в документации SDK).
3. Импорт в инструмент авториггинга Genies → проверка скинов на типовых idle/pushup позах.
4. Публикация как косметический ассет → привязка `cosmeticId` в Firestore каталоге.

Скриншоты контрольных поз и список известных ограничений по полигонажу добавить сюда после первого успешного импорта.
