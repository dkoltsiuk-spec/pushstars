# League screen

Main contains the authored LeaguePanel, opened from the left navigation tab. LeagueArt holds editable UI elements; the former placeholder remains inactive under LegacyLeaguePlaceholder. The default runtime tab remains Duel.

## Data and behavior

LeagueView initially shows LocalProfile as local progress, then loads the authenticated monthly leaderboard through LeagueClient. Online data supplies the hero tier, score, real UTC countdown, participant count and own position. Rows load in pages of 25; the own row stays pinned above navigation. CALIBRATE RANK / PLAY RANKED starts a server session, PREVIOUS SEASON browses archives, and CURRENT SEASON returns to live data. Network errors keep the last table labelled OFFLINE or show a retry action. See [online league architecture](../architecture/online-league.md).

## Illustrated presentation

The main trophy compositions remain the original hero.png, hero-silver.png, hero-gold.png and hero-diamond.png. All four share a 410-by-378 design-unit hero slot. LeagueView.HeroPositionFor aligns the trophy stem itself to the page center, accounting for the asymmetric surrounding artwork (normalized stem X: Bronze .52, Silver/Gold/Diamond .50). The hero uses a centered pivot so Unity preserveAspect centers the narrower square sprites inside the wide slot; a top-left pivot had shifted them 16 design units left. Validation checks the rendered CanvasRenderer mesh, including this padding. Sprite changes retain the authored size. The large tilted title uses the game's outlined Rubik BoldItalic and the current league accent color.

The active small trophy assets under Assets/_Project/UI/Sprites/League/Illustrated are cup-bronze, cup-silver, cup-gold and cup-diamond. These transparent image_gen extractions follow the existing hero cups: faceted materials, original handles and silhouette, without their surrounding bursts or stickers. The previous ornate trophies and score-crown are no longer bound to the scene. Source prompts are recorded in output/league/cup-extraction-prompts.json. The generated season-history icon and grayscale gym-wall backdrop remain; the latter is tinted orange, blue, gold or violet by LeagueVisualStyle. Prior procedural medals, frame card and ray background are inactive.

The trophy road shows only the current league's range: Bronze 0–400, Silver 400–800, Gold 800–1200. White ticks and numeric labels divide that range into 100-trophy intervals. Only the two endpoints have trophy icons: the current league at the start and the next league at the goal. Intermediate milestones have no trophy icons or claimable rewards. Leagues.Progress computes fill within this range, resetting at promotion (640 trophies means 60% of Silver). The centered total above the bar uses a matching 82-by-76 cup and a 60-unit score label, with no crown or remaining-to-next-league caption. Diamond shows a full bar, 1200 / MAX, a single cup; it does not invent a further league. Progress uses the authored slanted track/fill sprites and native horizontal image filling.

Ranked trophies are settled by finishRankedMatch after server confirmation. First calibration seeds 0 / 60 / 150 / 280 / 420 trophies for 1–9 / 10–19 / 20–34 / 35–49 / 50+ repetitions. A ghost win adds 12 plus max(0, consecutive active ranked days − 1), a loss subtracts 7 down to zero, and a draw adds zero. Pending results use LeagueClient's persisted outbox. The presentation change does not alter these rules.

Runtime actions share one row: a large yellow ranked button using the same btn_start plate as the home screen, plus a blue archive tile with the generated calendar icon. Player cards retain the game's slanted blue sprite and dark depth. Empty server display names render as PLAYER, and trophy totals autosize within the card.

LeagueHeroSwipe moves the current hero and title with the finger and renders a neighbouring hero/title one page-width away. Left drags reveal the next league, right drags the previous. On release, crossing 18% of the page width commits a 280 ms unscaled slide; shorter drags animate back. Endpoints resist dragging and do not wrap. The selected league and leaderboard request change only after the slide finishes. No entrance/fade animation is replayed during a swipe. Temporary neighbour objects are nonpersistent and cleaned up on completion or cancellation. Vertical gestures forward to the existing page ScrollRect. LeagueView snapshots the selected league and season for each standings request, rejects stale responses after another swipe, clears the old table immediately, and preserves the personal trophy total. The bar clamps that total to the viewed league range. Only players returned for the chosen league appear in the table; the personal rank footer is shown only when it belongs to that league. Network failure keeps the selected artwork and provides retry without fabricating leaders. Closing and reopening returns to the own league.

Opening League replays the existing unscaled entrance: hero, title, score/progress, season/status, then rows. Closing restores resting transforms. One clipped LeagueViewport scrolls the full page above the fixed bottom navigation (86 units reserved, plus online pinned-row space). Rows use 69-unit pitch. LeagueLayout scales to safe-area width, derives page height from active rows with a 700-unit minimum, and preserves/clamps scroll offset. Short screens scroll without shrinking the hero. The backdrop extends behind device insets.

## Editor tools and validation

- LeagueVisualUpgrade.Install upgrades Main in place, imports the generated PNGs, preserves data/entrance bindings, clears temporary online preview objects and backs up Main under Library/LeagueBackup. It can be rerun without duplicating artwork.
- LeagueSceneSetup.Build creates a new legacy screen; run LeagueVisualUpgrade.Install afterward for the illustrated presentation.
- LeaguePresentationValidation.Run checks a separate preview copy: local binding, staged entrance, cancellation/reopening, full-page drag/scroll, fixed navigation and last-row access at 390x644 / 390x844 / 430x932. It also renders all four themes, checks text fit, centered heroes, endpoint targets and the removed caption. Gesture checks cover both directions, endpoint limits, intermediate two-panel frames, release animation, short-drag snapback, cancellation, trophy-axis centering and vertical scroll forwarding. Server-shaped preview fixtures verify that a chosen league renders its own leaders and that the previous table disappears on the next swipe. Example scores exist only in the preview.

Renders and the validation report are written to output/league.
