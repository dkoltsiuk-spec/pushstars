# OTA-обновления интерфейса

После установки переходной версии приложения сцены **Main** и **Fight** могут
обновляться через интернет без нового IPA и без TestFlight.

## Как выпустить обновление

1. Открой обычную сцену `Assets/_Project/Scenes/Main.unity` или `Fight.unity`.
2. Передвинь элементы, поменяй картинки, материалы или другие объекты сцены.
3. Нажми **Ctrl+S**.
4. Выбери **Tools → Push Stars → OTA → Build & Publish Content Update**.
5. После успешной надписи `[OTA] Published` перезапусти приложение на телефоне.

Unity сама копирует сохранённые сцены в OTA-варианты, собирает изменённый
контент и публикует его на Firebase Hosting.

## Когда всё ещё нужен новый IPA

Новая сборка приложения нужна для изменений C#-кода, нативных плагинов,
разрешений iOS и настроек Player. Для расположения UI, сцен, изображений,
моделей, материалов и большинства анимаций достаточно OTA.

Первый IPA с OTA-загрузчиком обязателен один раз. Установленные до него версии
не умеют видеть удалённый каталог.
