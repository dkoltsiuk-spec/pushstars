# Данные пользователя на устройстве

Профиль, история и прогресс лиги используют локальное состояние. Вход в Firebase пока не синхронизирует игровой прогресс и не заменяет его серверным документом. Онлайн-рейтинг, число игроков и сезон не имитируются.

`LocalProfile` хранит `workouts_v1.json` в `Application.persistentDataPath`. Один результат содержит уникальный ID, UTC-время, режим, повторы, XP, соперника, исход и фактическую дельту трофеев. `LocalWorkoutLedger` сохраняет результат и общие счётчики одной операцией; повторный ID не начисляет награду снова. Запись идёт во временный файл с заменой предыдущего, состояние в памяти обновляется только после успешной записи. Некорректное сохранение не перезаписывается.

При отсутствии файла берутся прежние `profile.*` и `pending_xp` из PlayerPrefs. Старые трофеи, XP, победы, поражения и повторы сохраняются. История и серия побед до обновления неизвестны: фиктивные записи не создаются. Первый новый результат фиксирует перенесённые счётчики в файле. Кошелёк, кейсы и коллекция продолжают использовать существующий `CaseRewards`.

Завершение замера, боя с боссом/ghost и каждого тренировочного подхода записывается в историю. Законченные подходы остаются даже при выходе между сетами. Незавершённый подход не засчитывается. Ничья не является поражением; тренировка и замер не влияют на винрейт. Недельная активность считается по всем сохранённым занятиям за последние семь локальных календарных дней.

Главная показывает настоящие трофеи и балансы кошелька. Профиль показывает локальные XP/уровень, статистику и историю. Лига показывает реальный прогресс и собственную карточку без выдуманного места. Ghost подписан `YOUR GHOST`; его результат берётся из записи устройства. Демонстрационные экраны результатов доступны только в Editor preview.

Проверка: `Tools → Push Stars → Validate Local User Data` (`PushStars.Editor.LocalWorkoutRegression.Run`). Проверяются старт с нуля, перенос данных, повтор результата после перезапуска, повторный замер, отдельные тренировочные подходы, победа/ничья/поражение, сбой записи и повреждённое сохранение.

Для проверки на телефоне: завершить замер и тренировку; проверить XP, повторы, историю, недельную активность и трофеи; перезапустить приложение без интернета; завершить бой с ghost/боссом и проверить результат. Между устройствами данные пока не переносятся.
