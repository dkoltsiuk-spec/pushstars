# Модерация: фильтр ников, жалобы, блокировки

Требование App Store 1.2: фильтр, жалоба с реакцией, блокировка, контакт, правила с нулевой терпимостью. Единственный контент от игрока, который видят другие, — ник. Чата, картинок и текстов нет.

## Фильтр ников

Один и тот же фильтр в двух местах: `functions/src/nameFilter.js` и `Assets/_Project/Scripts/Core/NameFilter.cs`. Списки совпадают, `nameFilter.test.js` сверяет их между собой, образцы в тестах общие. Новое слово добавляется в оба файла.

- Телефон проверяет при вводе (`ProfileIdentityEditor.Save`).
- Сервер проверяет при сохранении (`updateDisplayName`) и при показе (`displayNameOf`), поэтому старые плохие ники и ники из старых сборок тоже скрыты: другие видят сгенерированный ник.
- Ник соперника в живой дуэли приходит с другого телефона мимо сервера, поэтому `LiveDuelLink` пропускает его через `NameFilter.Shown`.
- Сгенерированные ники обязаны проходить фильтр: `nameFilter.test.js` перебирает все 4096 сочетаний.

Слова делятся на два списка: `ANYWHERE` ловит внутри слова, `WHOLE_WORDS` только целым словом («spic» сидит внутри Spicy, «eban» внутри Lebanon).

## Жалобы

`PlayerActionsSheet` открывается из лиги, списка друзей и результата боя. `reportPlayer` пишет `reports/{reporter}_{target}`: один игрок на одну цель даёт одну запись. Три разных игрока с жалобой на ник скрывают его сразу (`users/{uid}.nameHidden`), до просмотра модератором. Жалоба на бота из пула сохраняется с `targetBot`.

Очередь модератора:

```bash
node tools/Moderation/reports.js
node tools/Moderation/reports.js --hide <uid> --report <reportId>
node tools/Moderation/reports.js --lift <uid>
node tools/Moderation/reports.js --close <reportId>
```

Условия обещают рассмотрение за 24 часа, поэтому очередь надо смотреть каждый день. Каждая жалоба также пишется в лог как предупреждение `player report`, на него можно поставить оповещение в Cloud Logging.

## Блокировки

`setPlayerBlocked` пишет `blocks/{uid}/list/{target}` и зеркало `blockedBy/{target}/list/{uid}`. Заблокированные в любую сторону:

- не встречаются в очереди, звонках в режиме ожидания и записанных боях (`avoidFor` в `liveDuel.js`);
- не входят в комнату друг друга по коду;
- перестают быть друзьями, висящий вызов снимается.

Телефон держит копию своего списка (`ModerationClient`): чтобы скрыть ник в таблице лиги и поиск заблокированного над кнопкой боя. Бот из пула не имеет аккаунта, его блокировка живёт только на телефоне; поиск и так не предлагает бота дважды. Список и разблокировка: Settings → Blocked players.

При удалении аккаунта блокировки в обе стороны удаляются (`onUserDeleted`).
