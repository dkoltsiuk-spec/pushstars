# Редактирование интерфейса

Основные сцены `Assets/_Project/Scenes/Main.unity`, `Boot.unity`, `Onboarding.unity`
и `Fight.unity` — источник интерфейса. Редактируйте их вне Play и сохраняйте Ctrl+S.
Сохраняются все сериализуемые свойства Unity: расположение, размеры, текст, цвет,
спрайты, настройки компонентов, ссылки, добавление и удаление объектов.
Отдельного списка разрешённых элементов и JSON с поправками больше нет.

Открыть экран: **Tools → Push Stars → Edit Screens → Main / Boot / Onboarding / Fight**.
В Main кнопки находятся в `MainCanvas/MirrorRoot/SafeArea/DuelPanel/ActionRow`,
нижнее меню — в `MainCanvas/MirrorRoot/SafeArea/BottomNav`.
Для редактирования скрытых панелей включайте их в Hierarchy; при запуске вкладками
и оверлеями по-прежнему управляет логика игры.

Генераторы основных сцен теперь создают только отсутствующие файлы. Обычная сборка
и PrepareForUBA сохраняют существующие основные сцены. Диагностическая testCV
по-прежнему генерируется при облачной сборке. Если в Fight потеряна ссылка на
MediaPipe, облачная сборка сообщает об ошибке вместо пересоздания экрана.

Изменения во время Play не сохраняются после его остановки. Динамические значения
(счётчики, профиль, таймеры), анимация, Layout Group и SafeAreaFitter продолжают
управлять своими свойствами во время игры. Меняйте соответствующий компонент или
его настройки, если он управляет нужным свойством. Prefab редактируйте в Prefab Mode
или применяйте Overrides к prefab, когда изменение должно затронуть все экземпляры.

## Для изменений кодом

Редактируйте существующую сцену или prefab адресно, сохраняя ссылки и остальные
ручные правки. Изменение чисел в старом генераторе больше не меняет существующий
экран. Не удаляйте сцену ради её пересоздания. Новые функции подключайте к сохранённым
объектам через Inspector или отдельную адресную миграцию. Перед сменой исполнителя
сохраните сцену; не перезаписывайте файл, пока в открытой Unity есть несохранённые правки.
